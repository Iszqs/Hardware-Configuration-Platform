# 硬件配置页面 UI 优化计划

## 任务清单

1. 移除硬件配置下"选择单个设备进行配置"文字
2. 优化配置结果显示，使其更便于中老年人直观看到
3. 将配置和检测结果移动到硬件配置页面的右侧，左侧显示卡片，右侧显示结果

## 实施计划（TDD）

### 阶段 1: 移除副标题文字
- 修改 `OneClickConfig.vue`，移除第 7 行的 `<p>选择单个设备进行配置</p>`

### 阶段 2: 左右布局改造
- 将页面分为左右两栏
- 左侧：设备卡片网格
- 右侧：结果显示区域（配置结果 + 检测结果）

### 阶段 3: 结果显示优化（适老化）
- 增大结果卡片字体
- 增大 LED 指示灯尺寸
- 更明显的成功/失败颜色对比
- 更清晰的图标和文字层次
