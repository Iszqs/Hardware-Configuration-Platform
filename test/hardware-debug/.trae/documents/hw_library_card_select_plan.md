# 硬件库卡片选中与按钮优化计划

## 需求
1. 选中硬件时卡片同时高亮，且边框有明显变化
2. 选中硬件时显示新增/编辑/删除按钮
3. 三个按钮颜色各不相同，易于区分

## 当前问题
- 选中硬件时，新增按钮变成了不可见的 `btn-tertiary`（灰色），因为当前逻辑判断新增只在"仅选中卡片但未选中硬件"时显示为主色
- 选中卡片的边框变化不够明显（仅颜色变蓝）

## 修改文件
- `src/views/HardwareLibrary.vue`

## 修改内容

### 1. 卡片选中边框更醒目
给 `.category-card.selected` 添加 `border-width: 2px` 和更强的阴影效果

### 2. 修复按钮颜色逻辑
- 新增：卡片选中时始终 `btn-primary`（蓝色），不因选中硬件而变灰
- 编辑：选中硬件时 `btn-success`（绿色）
- 删除：选中硬件时 `btn-danger`（红色）
- 均禁用时显示 `btn-secondary`（灰色）

### 3. 修改模板按钮 class 逻辑
简化按钮颜色判断，确保选中卡片时三个按钮都能各显其色
