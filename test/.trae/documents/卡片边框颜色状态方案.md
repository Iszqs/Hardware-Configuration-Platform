# 硬件配置页面卡片边框颜色状态方案

## Summary
为硬件配置页面的设备卡片添加状态边框：配置和检测按钮都成功时边框变绿色，任意失败则边框变红色。

## Current State Analysis

**现有代码结构** (`OneClickConfig.vue`)：

1. **卡片状态管理**：
   - `configuredIndexes` (L134)：仅存储配置成功的卡片索引
   - 仅有 `configured` class 用于配置成功的卡片 (L355-L357)

2. **按钮操作结果**：
   - `configSingle(idx)`：配置结果存入 `lastResult.value.status` ('success'/'failed')
   - `inspectSingle(idx)`：检测结果存入 `lastInspectResult.value.passed` (true/false)

3. **现有卡片 class** (L17-L20)：
   ```vue
   :class="{
     'selected': selectedIndex === idx,
     'configured': configuredIndexes.includes(idx)
   }"
   ```

4. **问题**：
   - `configured` class 只检查索引是否存在，不区分成功/失败
   - 没有跟踪检测结果对卡片的影响
   - 无法实现"配置 AND 检测都成功才变绿"的需求

## Proposed Changes

### 1. 添加卡片状态跟踪变量

**文件**: `OneClickConfig.vue`

添加两个响应式变量分别跟踪每个卡片的配置和检测状态：

```javascript
// 存储每个卡片的操作状态: { configSuccess: bool, inspectSuccess: bool }
const deviceStatuses = ref({})
```

### 2. 更新操作结果保存状态

**`configSingle(idx)` 函数** (L145-L201):
- 成功/失败都记录到 `deviceStatuses[idx].configSuccess`
- 移除 `configuredIndexes` 逻辑，改用 `deviceStatuses`

**`inspectSingle(idx)` 函数** (L203-L242):
- 成功/失败都记录到 `deviceStatuses[idx].inspectSuccess`

### 3. 更新卡片 class 绑定

**卡片 class** (L17-L20):
```vue
:class="{
  'selected': selectedIndex === idx,
  'status-success': getDeviceStatus(idx) === 'success',
  'status-failed': getDeviceStatus(idx) === 'failed'
}"
```

添加辅助函数：
```javascript
function getDeviceStatus(idx) {
  const status = deviceStatuses.value[idx]
  if (!status) return null
  if (status.configSuccess && status.inspectSuccess) return 'success'
  if (status.configSuccess === false || status.inspectSuccess === false) return 'failed'
  return null
}
```

### 4. 添加 CSS 样式

**`.device-card.status-success`** (L355 附近):
```css
.device-card.status-success {
  border-color: var(--color-success);
}
```

**`.device-card.status-failed`**:
```css
.device-card.status-failed {
  border-color: var(--color-error);
}
```

## Verification Steps

1. 刷新页面，确保无语法错误
2. 点击配置按钮（成功）→ 边框不变色（因为检测还未成功）
3. 点击检测按钮（成功）→ 边框变绿色
4. 点击检测按钮（失败）→ 边框变红色
5. 重新配置（成功）但检测（失败）→ 边框变红色
6. 两个都成功 → 边框变绿色
