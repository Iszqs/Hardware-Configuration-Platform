# 串口配置弹窗改为竖向布局实施计划

## 1. 现状分析

### 1.1 当前布局
当前串口配置弹窗（SerialModal.vue）采用两列网格布局：
- 弹窗宽度：max-width: 480px
- 表单布局：form-grid-2col（2×2网格）
- 输入框排列：串口号/波特率在上排，数据位/校验在下排

### 1.2 用户需求
用户希望将弹窗改为竖向布局，即所有输入框单列垂直排列。

## 2. 需要修改的文件

仅需修改一个文件：
- `d:\Users\OL\Desktop\硬件配置平台\test\hardware-debug\src\components\SerialModal.vue`

## 3. 具体修改内容

### 3.1 修改表单布局为单列竖向

**修改位置**: SerialModal.vue 第18行（表单容器）

**当前代码**：
```html
<div class="form-grid form-grid-2col">
```

**修改为**：
```html
<div class="form-grid">
```

### 3.2 调整弹窗宽度

由于改为单列布局，可适当减小弹窗宽度：

**当前代码**：
```css
.modal {
  width: 90%;
  max-width: 480px;
  ...
}
```

**修改为**：
```css
.modal {
  width: 90%;
  max-width: 360px;  /* 从480px减小到360px */
  ...
}
```

### 3.3 移除两列布局样式（可选）

可以保留 `form-grid-2col` 样式以备将来使用，或者移除。

## 4. 预期效果

修改后的弹窗将：
- ✅ 表单改为单列竖向布局（4个输入框垂直排列）
- ✅ 弹窗宽度从480px减小到360px
- ✅ 整体更加紧凑，适合竖向显示
- ✅ 保持所有功能完整性

## 5. 实施步骤

1. **修改表单容器class** - 移除 `form-grid-2col` 类
2. **调整弹窗宽度** - 将 `max-width: 480px` 改为 `max-width: 360px`
3. **测试验证** - 确保弹窗显示正常，功能完整

## 6. 验证方式

1. 打开前端页面
2. 点击状态栏的串口状态图标
3. 检查弹窗是否为单列竖向布局
4. 确认所有配置选项都能正常选择
5. 测试连接和断开功能是否正常
